## Sprint Number & Dates

**Sprint Number:** Sprint 3
**Sprint Duration:** 11.02.2026 – 04.03.2026

## Sprint Goal

The goal of Sprint 3 is to finalize MVP phase of the project.
Core functions must work E2E, frontend being integrated with backend.
Also OPS tasks like Jenkins pipeline and Docker images must be implemented.

## Selected Product Backlog Items

### Functional 
- Teacher can create a course, view his courses, remove or update specific course
- Teacher can upload XML file with enrolled students
- Teacher can see list of attending students
- Teacher can remove student from enrollments list
- Teacher can create a lecture of specific course
- Student can mark attendance to lecture by providing lecture code
- Backend signin actually returns JWT token that encodes user data

### Non-Functional
- Frontend private paths encapsulated in dedicated layout
- Frontend private cabinet menu is different for each role
- Different roles can't access other parties cabinet
- Jenkins pipeline is implemented
- Dockerfiles are defined for fron and back-end
